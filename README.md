# Oraqel Code Site

Plain HTML and CSS, ready to deploy to Vercel.

## File structure
- `index.html` — Home
- `privacy/index.html` — Privacy Policy at /privacy
- `terms/index.html` — Terms of Service at /terms
- `support/index.html` — Support at /support
- `styles.css` — Shared styles

## Deployment
Drop this folder into a GitHub repo, then import the repo in Vercel. Vercel auto-detects it as a static site, no build step, no config needed.

## Future updates
- Replace the CSS phone mockups in `index.html` with real screenshots when ready.
- Update the App Store button `href="#"` to your real App Store URL once the app is live.
- Update effective dates in `/privacy` and `/terms` if you make material changes.
